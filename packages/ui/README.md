# @novacommerce/ui

Shared NovaCommerce design system package — tokens, Tailwind theme, and shadcn/ui primitives.

## Usage

```tsx
import '@novacommerce/ui/globals.css';
import { Button } from '@novacommerce/ui/components/button';
```

## Contents

- `src/styles/globals.css` — Tailwind v4 theme + NovaCommerce tokens
- `src/components/` — Customized shadcn/ui primitives, EmptyState, ErrorState, NovaCommerceLogo
- `src/lib/utils.ts` — `cn()` utility

See `docs/design-system.md` for full documentation.
